## 1. نظرة عامة على النظام

تم تصميم وتطوير هذه البوابة لتوفير تجربة مستخدم عصرية وفاخرة لبوابات تسجيل الدخول بالشبكات اللاسلكية (Captive Portal)، مع الحفاظ على التوافق التام بنسبة 100% مع متغيرات وأوامر نظام **MikroTik RouterOS**:
- **التعرف التلقائي الفوري (Instant Captive Portal Detection):** تنبثق شاشة تسجيل الدخول في أقل من 50 جزء من الثانية فور الاتصال بالواي فاي على جميع الأجهزة (Android, iOS, Windows, macOS).
- **تصميم زجاجي عصري فاخر (Dark Turquoise & Gold Glassmorphism):** طابع لوني فيروزي ملكي مع لمسات ذهبية وتأثيرات زجاجية كريستالية نقية.
- **عمل كامل بدون إنترنت (100% Offline):** جميع الخطوط، الأيقونات، الأكواد، ومحركات الجافاسكريبت مدمجة ومخزنة محلياً لتعمل فوراً من ذاكرة الراوتر قبل تسجيل الدخول.

## 2. الميزات والأنظمة المدمجة

### 1) نظام تسجيل الدخول الذكي وإدارة الجلسات
- دعم إدخال كرت المستخدم (اسم مستخدم فقط أو اسم مستخدم وكلمة مرور).
- حفظ الكرت في الذاكرة المحلية (`hotCookie`) لتسجيل الدخول التلقائي عند العودة.
- ماسح باركود ذكي مدمج بالكاميرا (QR Code Camera Scanner) يدعم التحميل السريع عند الطلب (Lazy Loading).

### 2) لوحة معلومات واستهلاك الكرت المباشرة (#status)
- عدادات فورية لحجم التنزيل (Download) والرفع (Upload) والرصيد المتبقي.
- مؤشر الوقت المستهلك والوقت المتبقي للجلسة.
- قائمة تغيير سرعة الكرت فورياً للمحافظة على رصيد الكرت.
- أزرار مباشرة للاستراحة، البث المباشر للقنوات، وتطبيقات مراقبة الاستهلاك.

### 3) نظام النقاط والمكافآت (Loyalty & Points System)
- تسجيل المشتركين برقم الهاتف وربطهم برصيد النقاط.
- إمكانية طلب سلفة كرت عند نفاد الرصيد.
- استبدال النقاط بكروت إنترنت مجانية وحفظ الكروت المكتسبة.
- لوحة إدارة حساب نقاط متكاملة مع إمكانية حفظ واسترجاع الكروت.

### 4) نظام الإعلانات والتنبيهات المتقدم (Notifications & Announcements)
- شريط أخبار وتنبيهات متحرك (Dynamic News Ticker).
- نوافذ منبثقة تفاعلية ذكية للرسائل الهامة والعروض المؤقتة.
- بنر عروض تفاعلي حديث وسريع يدعم اللمس والسحب (Touch Swipe Slider) ومؤشرات التقدم.

## 3. هندسة الأداء الفائق والسلاسة (60/120 FPS)

تمت معالجة كافة معوقات التمرير والأداء على الهواتف الذكية (بما فيها الهواتف الاقتصادية والقديمة):

### 1) التمرير الأصلي لنافذة النظام (Native Root Window Scrolling)
- تحرير التمرير وجعله مباشراً على مستوى `html` مع تفعيل التسارع العتادي (`-webkit-overflow-scrolling: touch` و `touch-action: pan-y`).
- إلغاء التمرير الداخلي المحبوس في `body`، مما يمنح استجابة فورية بنسبة 1:1 مع حركة الإصبع دون أي احتكاك أو ثقل.

### 2) تحرير أحداث اللمس (100% Passive Touch Events)
- إزالة الاستماع الإجباري غير السلبي (`{ passive: false }`) أثناء تصفح الصفحة، وتفعيله فقط وبشكل مشروط عند فتح النوافذ المنبثقة (Modals) لحجز التمرير الخلفي وإلغائه فور إغلاقها.

### 3) القضاء على التمويه المتداخل (Single-Pass Glass Blur)
- حل مشكلة البطء في صفحة الحالة (`#status`) عبر إزالة الفلاتر المتكررة داخل العناصر الفرعية، والاعتماد على التمويه الكريستالي الموحد للبطاقة الأم، مما خفض استهلاك معالج الرسوميات (GPU) بنسبة تفوق 85%.

### 4) عزل الخلفية المتحركة وتسريع التحويلات ثلاثية الأبعاد
- عزل الخلفية الفيروزية والأيقونات العائمة في طبقات GPU منفصلة (`contain: strict; transform: translateZ(0)`).
- استخدام `translate3d` في التحريكات، مما يمنع إعادة رسم الطبقات (Zero Repaint Overhead) أثناء التمرير.

## 4. منظومة الخطوط والصور المحلية (Offline 100%)

- **الخطوط المدمجة:** تم تضمين خط المراعي العربي الأصلي بكافة أوزانه السليمة ثنائياً (`WOFF2`):
  - `almarai-300` (خفيف - Light)
  - `almarai-400` (عادي - Regular)
  - `almarai-700` (عريض سميك - True Bold)
  - `almarai-800` (عريض جداً - Extra Bold)
  - خطوط بديلة مدعومة محلياً: `Tajawal` و `Cairo`.
- **الصور والإعلانات:** نقل كافة صور العروض والإعلانات بأبعادها وتنسيقاتها القياسية السليمة في مجلد `adimg/`.

## 6. دليل الرفع والتثبيت على راوتر مايكروتك

عند نقل القالب إلى راوتر مايكروتك:

### 1) الملفات المطلوبة للراوتر:
انسخ الملفات والمجلدات التالية وضعها داخل مجلد `hotspot` في الراوتر عبر برنامج **Winbox** (قائمة **Files**) أو عبر **FTP**:
- ملفات الـ HTML: (`index.html`, `login.html`, `status.html`, `logout.html`, `alogin.html`, `redirect.html`, `mobasher.html`).
- المجلدات: (`config/`, `css/`, `fonts/`, `img/`, `js/`, `adimg/`).

### 2) ملفات لا تُرفع للراوتر (لتوفير ذاكرة الفلاش):
لا ترفع ملفات بيئة التطوير: `node_modules/`, `src/`, `server.ts`, `package.json`, `tsconfig.json`.

## 7. محاكي بيئة التطوير وخادم Node.js

يحتوي المشروع على خادم محاكاة متكامل (`server.ts`) يتيح تجربة واختبار الهوتسبوت محلياً مع محاكاة حية لنقاط نهاية مايكروتك:
- `/login?var=callBack` - محاكاة تسجيل الدخول واختيار السرعات.
- `/status?var=callBack` - محاكاة استهلاك البيانات والعدادات الحية.
- `/logout?var=callBack` - محاكاة تسجيل الخروج.

### أوامر التشغيل:
```bash
# تثبيت الحزم
npm install

# تشغيل الخادم
npm run dev

# بناء المشروع والتحقق من الأنواع
npm run build
```
